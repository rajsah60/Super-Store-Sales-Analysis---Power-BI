# Super Store Sales Analysis - Power-BI

## 📊 Project Overview

 A Power BI practice project analyzing Superstore Sales, Profitability, customers, shipping performance, and product.


## 🎯 Objectives

- Analyze overall sales and profit performance.
- Identify high-performing regions and category.
- Compare monthly sales and profit year-over-year.
- Analyze the shipping and payment methods.
- Identifying Top-performing sub-Categories.
- Generates some insights and recommendation.


## 📌 KPIs

 - Total Sales : 1.6M
 - Total Orders : 22K
 - Total Profit : 175K
 - Average Ship Days : 4


## 📈 Dashboard Analysis

 - Sales by Payment Mode
 - Sales by Region
 - Sales by Segment
 - Sales by Ship Mode
 - Monthly Sales YOY
 - Monthly Profit YOY
 - Sales by category
 - Top 3 sub-category
 - Slicer on Region
